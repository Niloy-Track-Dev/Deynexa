## Reporting a Vulnerability

The Daynexa team takes security and user privacy seriously. Because Daynexa is an offline-first application with no backend servers, user accounts, or cloud tracking, security primarily concerns local data integrity and dependency safety.

If you discover a security vulnerability or potential data leak in Daynexa:

1. **Do not open a public issue.**
2. Please report the issue through [GitHub Security Advisories](https://github.com/niloymitra/daynexa/security/advisories/new) or by contacting the project maintainer via their GitHub profile.
3. Include a detailed description of the vulnerability, steps to reproduce, and any suggested remediations.

We will review your submission promptly and coordinate a patch release.
