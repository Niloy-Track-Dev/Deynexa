# Daynexa Screenshots

This directory is dedicated to visual assets and UI preview captures for Daynexa.

## Expected Preview Files

| Screenshot | Screen | Description |
| :--- | :--- | :--- |
| `today.png` | **Today View** | Daily timeline, progress card, and active tasks |
| `calendar.png` | **Calendar View** | Monthly matrix and daily productivity dots |
| `statistics.png` | **Analytics & Heatmap** | 14-week consistency heatmap and streak metrics |
| `categories.png` | **Categories** | Custom category tags and icon badges |
| `settings.png` | **Settings** | Theme switcher, time format, and JSON backup controls |

> **Note for Contributors:** When adding or updating screenshots, please capture them at 1080x2400 (or standard modern aspect ratio), optimize with PNG compression, and ensure light/dark balance.
